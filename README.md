# Генератор КП по SEO — Qmedia

Внутренний веб-инструмент для отдела продаж Qmedia: по параметрам проекта формирует
коммерческое предложение по SEO — считает стоимость и часы по 5 направлениям, отдаёт
**PDF** (КП для клиента) и **Excel** (план + расчёт) и сохраняет каждую генерацию
отдельным JSON на сервере (можно открыть и пересчитать заново).

## Возможности

- Визард ввода параметров проекта с живым расчётом стоимости.
- 5 направлений SEO (Коммерческое, Информационное, GEO, SERM, Техподдержка) — в КП всегда
  присутствуют все, с пометкой «включено / не входит». Внутри можно убрать работы из
  каталога или добавить свои.
- Расчёт стоимости и часов по алгоритму из `sources/Расчет SEO.xlsx`.
- Экспорт в **PDF** (A4 landscape, фирстиль Qmedia) и **Excel** (2 листа: «Расчёт» и
  «План работ»).
- Сохранение КП в JSON, список сохранённых, импорт ранее сохранённого JSON с пересчётом.

## Стек

Next.js 14 (App Router) · TypeScript · Tailwind CSS · `@react-pdf/renderer` (PDF) ·
`exceljs` (Excel) · `zod` (валидация) · `vitest` (тесты).

## Запуск

Требуется Node.js 18+.

```bash
npm install
npm run dev      # режим разработки → http://localhost:3000
# сборка и прод-запуск:
npm run build
npm start
npm test         # юнит-тесты расчёта (включая «золотой тест» из Excel)
```

> Если порт 3000 занят, Next выберет следующий свободный (например 3001) — смотрите
> сообщение в консоли.

## Как работает расчёт

Логика повторяет `sources/Расчет SEO.xlsx`. Все константы и коэффициенты — в
[`lib/seo-config.ts`](lib/seo-config.ts), сама формула — в [`lib/calc.ts`](lib/calc.ts):

- Базовая стоимость `750`, стоимость часа `75` BYN.
- Цена направления за месяц = `base × коэф.направления × произведение применимых коэффициентов`,
  округление до целого. Часы = `round(цена / 75)`.
- Наборы коэффициентов у направлений различаются (Коммерческое/GEO используют все,
  Информационное/SERM — без страниц/ошибок/конкуренции, Техподдержка — только
  страницы/ошибки/опыт).
- Итог за месяц — сумма по включённым направлениям; итог за проект = месячный × срок (3 или 6).

Чтобы поменять ставки, коэффициенты или варианты — правьте `lib/seo-config.ts`.
Перечень работ по направлениям — [`lib/works-catalog.ts`](lib/works-catalog.ts).

## Хранение данных

Каждое КП сохраняется в `data/proposals/<id>.json` (папка `data/` в `.gitignore`).
JSON содержит введённые параметры, выбор направлений/работ и снимок расчёта. При
генерации PDF/Excel и при импорте расчёт всегда выполняется заново из параметров.

## Брендинг и шрифты

- Фирстиль Qmedia: основной цвет — **зелёный** `#53BD35`, акцент — **жёлтый** `#FFDE00`
  (сверены с CSS qmedia.by). Чёрный почти не используется. Палитра — в
  [`lib/company.ts`](lib/company.ts) (`BRAND`) и `tailwind.config.ts`.
- Логотипы (`public/brand/logo-*.svg`) — из Figma-стайлгайда Qmedia: вордмарк и знак-кружок
  в белом/зелёном/чёрном вариантах. В вебе используются SVG; в PDF — белые растровые
  (`qmedia-*-white.png`), т.к. `@react-pdf/renderer` не грузит SVG через `<Image>`.
- Корпоративные фото — `public/images/print-*.jpg` (используются на обложке PDF).
- Оформление PDF повторяет референс `sources/cp-development.pdf`: зелёный заглавный слайд
  с фото и логотипом, зелёный градиентный колонтитул с Q-watermark на каждом слайде,
  отдельный слайд «Смета», жёлтые акценты.
- Шрифт — PT Sans (OFL, с кириллицей) в `public/fonts/QmediaSans-*.ttf`: в PDF
  регистрируется в `ProposalPdf.tsx`, в вебе подключён через `@font-face` в `globals.css`.

## Принятые решения и допущения

- **Валюта** — BYN. **Срок** (3/6 мес): расчёт Excel — стоимость за месяц, итог = месяц × срок.
- Поля **«Ссылочное продвижение»** и **«Конкуренция»** добавлены в форму (есть в Excel).
- **«Что продвигаем»** не влияет на цену (нет такого коэффициента в Excel) — используется
  как текстовый параметр.
- Вариант **«до 500» страниц** в исходном Excel отсутствует — задан коэффициент `1.1`
  (между «до 50»=1.0 и «до 1000»=1.2), правится в `lib/seo-config.ts`.
- Авторизация для MVP не реализована (внутренний инструмент).
- Нумерация страниц в PDF не выводится (динамические узлы `@react-pdf/renderer` в связке
  с бандлингом Next не дают вывода) — подвал содержит название компании и сайт.
