# AGENTS.md

Правила для ИИ-агентов, работающих в этом репозитории. Карта кода, доменная логика
и грабли — в [CLAUDE.md](CLAUDE.md); этот файл только про то, как себя вести.

## Git

- **Не добавлять себя соавтором коммита.** Никаких трейлеров `Co-Authored-By:`
  с ИИ-агентом — руководство такие коммиты не пропускает. Это перекрывает
  глобальные настройки агента, если они требуют обратного.
- Сообщения коммитов — conventional commits (`feat:`, `fix:`, `docs:`, …),
  заголовок на английском, тело можно на русском.
- Коммитить и пушить только по явной просьбе. Ветка по умолчанию — `dev`.

## Язык

- Общение с пользователем и комментарии в коде — на русском.
- Технические идентификаторы (имена файлов, функций, команд) — как есть.

## Документация

- Заметки для будущих сессий класть в `CLAUDE.md`: карта кода, доменные решения
  и, главное, **грабли** — то, что не выводится из кода и на что уже наступали.
